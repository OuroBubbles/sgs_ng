# 07 · P0 实施记录

日期：2026-10-16。阶段结论：**浏览器与 Windows 原生纵切已完成；P0 原生双端退出条件尚未满足。**

## 实际实现

- Vite + Svelte + TypeScript 工程，单一应用，pnpm lockfile。
- Pixi WebGL 战场与角色席位、目标指示、手牌和响应牌解释。
- 同源预览与提交校验，确认后同步更新手牌、体力和提交记录。
- 请求 ID 与 revision 防止重复、过期和重置前的回复再次写入。
- 键盘、触控尺寸、窄屏纵向布局，开启/关闭战场表现不影响演示结果。
- 官方 Spine 4.2 样本，1／8 实例，行走/奔跑，暂停/继续，帧间隔采样与 JSON 导出。
- 骨骼与贴图共享；面板卸载释放实例、应用、骨骼缓存与 atlas。静态战场按视图变更重绘；页面不可见时暂停表现 ticker。
- Tauri Rust 入口、应用配置、能力声明和桌面/Android 图标。
- 平台检查脚本与原生构建命令。

## 运行与检查

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:ui
pnpm format:check
pnpm platform:check
```

浏览器访问 `http://127.0.0.1:1420`。`test:ui` 使用生产构建，因此在客户端改动后应先 build。测试不会运行两个参考项目。

当前验证使用 Node 24.21.0、pnpm 11.25.0；核心客户端依赖为 Svelte 5.57.2、Vite 8.3.4、TypeScript 5.9.3、PixiJS 8.22.0、Spine 4.2.120，具体解析见 lockfile。TypeScript 暂用兼容类型感知 lint 的 5.9 系列。

## 验证证据

- 12 项单元/行为测试：原有选择提交边界，加上切牌联动和桌面/窄屏/矮横屏的席位布局边界。
- 16 项浏览器检查：8 类场景分别在桌面与触控模拟运行，额外切换到 390×844 验证窄屏；包括真实 WebGL、Spine、详情、长按、选择保留、横屏操作同屏和无外部来源请求。
- 浏览器检查收集 pageerror 与 console.error；通过时均为空。
- 浏览器文档使用 Tauri 配置中的生产 CSP；Pixi 安装官方无动态求值适配入口，避免仅在普通网页中启动正常、进入应用壳后失败。
- TypeScript/Svelte 检查无错误和警告，ESLint 通过，生产构建通过，格式检查独立运行。
- 截图保存在 `.artifacts/p0/battle-desktop.png`、`battle-touch.png`、`portrait-desktop.png`、`spine-desktop.png` 等文件；测试重新运行会更新截图。

浏览器为 Playwright Chromium 156.0.8078.4。触控项目是桌面浏览器的设备模拟，**不是 Android WebView 实机**。headless 环境中的采样不用于证明 60 fps；p95 指滚动最多 600 个浏览器帧间隔样本，未拆分 CPU/GPU，也没有采集系统内存。

## 原生链路的实际结果

首次构建因缺少 Rust/Cargo/MSVC 失败。本轮已在 `.tools` 准备 Rust 1.99.1、MSVC 14.44.35207 和 Windows SDK 10.0.26100.0，并成功完成 Windows Debug 与 Release 构建。

实际启动这两种原生程序，连接本机 WebView2 155.0.4283.45，完成出牌、体力变化、8 实例 Spine 播放与面板关闭检查，console errors 为空。当前 Release 可执行文件约 10.4 MB，压缩包与许可证位于 `.artifacts/builds/`。Rust 链接器输出一条关于生成 import library 的提示性 warning；没有将其算作无警告编译。

`pnpm platform:check` 输出 `.artifacts/p0/platform.json`：

- JDK 17.0.20.1 与 Android platform-tools/ADB 可用。
- Android SDK 位于已有 `ANDROID_HOME`；现已具备 Platform 36、Build-Tools 36 与 NDK 27.2.12479018。
- `adb devices -l` 未发现连接设备。

Android 工程已初始化，ARM64 `.so` 编译通过并确认 ELF64/AArch64。CLI 在非管理员 Windows 的 JNI symlink 步骤受阻，通过普通 JNI 文件回退成功完成 Gradle 打包。当前 APK 约 21.0 MB，appid 为 `dev.sgsng.game`，版本 0.1.0/1000，minSdk 24、target/compileSdk 36、ABI arm64-v8a，Debug v2 签名校验通过。具体命令与限制见 [开发指南](08-development-guide.md)。

JavaScript 与 Rust 均已有 lockfile。Rust/MSVC 位于项目工具目录，未安装全局 Visual Studio，也未修改系统 Developer Mode。Android 真机测量仍未进行。
