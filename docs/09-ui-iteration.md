# 09 · noname 交互参考与本轮 UI 改进

日期：2026-10-16。本文记录 P0 交互改进；后续已接入正式规则，当前客户端契约与验证见 [16 · 正式规则客户端](16-local-client.md)。

## 源码参考与取舍

| 本地参考                                              | 吸收的逻辑                                           | 本轮对应实现                                                            |
| ----------------------------------------------------- | ---------------------------------------------------- | ----------------------------------------------------------------------- |
| noname/game/index.js 的 game.check，约 6941–7049 行   | 卡牌、目标和最终确认分别更新；复杂选择不应盲用旧缓存 | 保持执行侧统一校验；切牌后只保留仍合法的目标                            |
| 十周年UI/extension.js 的 checkTarget hook，约 3014 行 | 可选、已选、不可选状态要能直接辨别                   | 可选标签、已选标签、不可选席位淡化、目标连线                            |
| 十周年UI 的手牌布局和抽牌布局                         | 根据容器宽度安排牌面与反馈，避免位置写死             | 本轮先固定横屏操作同屏，并共享战场绘制/命中坐标；大手牌重叠布局仍待后续 |
| noname 的桌面牌和操作提示                             | 玩家需要看清刚发生了什么                             | 从已提交记录展示最近三张桌面牌和目标，不另造规则状态                    |

这里只迁移交互思路，没有复制参考项目代码、资源或全局 game/ui/\_status 管理方式。自动确认没有默认启用，当前仍需用户明确确认出牌。

## 新的代码边界

- [selection.ts](../src/client/interaction/selection.ts)：当前保留快捷键守卫；正式选择反馈由规则与主持侧提供。
- [layout.ts](../src/client/table/layout.ts)：席位矩形的唯一坐标来源，Canvas 和 DOM 点击区域共用。
- [HandCard](../src/client/panels/HandCard.svelte)：选中反馈、右键详情与触摸长按，滑动时取消长按。
- [CardFace](../src/client/panels/CardFace.svelte)：手牌、桌面牌和详情共用牌面表现。
- [CardInspector](../src/client/panels/CardInspector.svelte)：原生 dialog 负责焦点隔离；查看详情不改选择。

已提交记录保存本次使用的牌面快照，因此手牌移除后桌面仍可正确显示。这里标明“已结算”，不把演示记录误称为正式处理区。

Spine 验证器改为按需加载，主入口 JS 从此前约 504 kB 降到约 179 kB（本轮构建，未压缩为 gzip 的 minified 产物）；其他渲染模块和骨骼模块仍为独立分块。不能只用入口大小声称总体运行内存下降。

## 验证与待办

本轮 12 项单元/行为测试和 16 项浏览器检查通过。覆盖：合法目标保留、非法目标清除、重复点击取消、席位边界、详情不改选择、模态时禁用游戏快捷键、触摸长按、横屏无纵向溢出，以及原有 Spine 和提交检查。

Windows 原生 WebView2 已额外验证提交和 8 实例 Spine。截图位于 `.artifacts/p0/`；Android 原生构建与实机结果另见 STATUS。
