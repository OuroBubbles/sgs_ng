# 35 · 响应限制、具名选择与三将

更新：2026-10-17。新增马超（马术、铁骑）、周瑜（英姿、反间）、貂蝉（离间、闭月），当前二十四名可选标准武将。默认人类甲席和基础 AI；Android 构建仍等桌面完成后开展。

## 单次效果禁止响应

本章记录初次实现；后续 [54](54-named-response-blocks.md) 增加 names 参数与具名过滤，铁骑明确只禁闪。responseTimes 现在必须传入实际响应牌名，实际代打者和受益者分别保留。

[CardEffect.blockResponses(ctx, actor, reason)](../src/rules/cards/plan.ts) 在本效果声明中记录受限角色与原因。和无双的最低响应次数一样，它是有生存期的 World 数据，写入事实和效果快照，接受纯查询与封口检查。

禁止响应优先于最低次数。CardBook.responseTimes 返回 0，正常杀不开放响应；直接调用 respond 也在响应请求的实时条件中检查受益者，不能通过八卦提供或护驾委托绕过。直接请求失败仍有 unavailable 结果，但不开放 responseRequested 窗口或玩家选择。

限制作用于本 EffectId，新增、转移或显式重复的效果重新指定目标并独立声明。流离不把旧目标的铁骑结果带给新目标；来源仍持有铁骑时，可对新目标重新发动。

马术是普通来源距离修正，和坐骑相加，由最终距离裁剪保证非本人至少为一。铁骑是在来源指定目标时自愿发动的普通判定，使用改判后的最终颜色；接受后失去技能不撤销判定结果，目标/效果失效则不继续改写。

## 单次用牌的反制限制

规则调用者可在 UseIntent 中传入 prohibitedCounters 牌名数组。它在进入用牌流程时复制，随 card.used、UseSnapshot、EffectRef、CardUseRef 保存，延时牌也能带到未来的生效流程。它不改变整种牌定义或角色的永久用牌权限。

反制按当前 subject 检查，而不是把根效果禁令套到所有后续反制牌。机会保留反制牌型目录，每层征询过滤当前 subject 的禁令；直接以 counter 时机用牌也由最终验证拒绝被禁止的牌。禁止无懈的牌仍可被作者提供的其他反制牌反制，该反制牌自身又可以被普通无懈反制。没有合法反制牌型时不打开征询；显式 contestCounter 仍收束结果。

离间先通过 JointSelection 验证费用、两名其他男性角色及有序的决斗方向，再把费用、次数和技能宣告同次提交。第一名是先出杀的响应者，第二名是决斗发起者；客户端为多目标选择标注顺序。支付后调用正常 book.use，产生独立 UseId、零材料语义决斗和无懈禁令，实际决斗者的集智、无双等技能照常生效，伤害归实际获胜者。

性别是宣告时的资格，接受后的性别变化/技能失去不撤销费用；实际发起者的当前存活、用牌和目标禁令仍由 book.use 重查。后续无法使用不退费用。取消不计次，同一阶段的次数不会因为丢失/重获技能清零，下一阶段独立。

## 具名选项和反间

[chooseOne](../src/core/decisions/choice.ts) 生成普通 Decision：选项由稳定字符串 ID 和可读 label 构成，展示快照与实时校验分开，不借用触发排序。作者直接 await ctx.ask(chooseOne(...))，可以设置 optional 和 available；无需注册专用 Manager 或技能配置语言。

客户端新增 choose-option 面板，以正式答复接口提交 ID；基础 AI 选择合法的首项。该基础策略不根据他人的暗牌猜测。暂停、授权席位、旧令牌和最终校验继续由既有 Session/Decision 管线负责。

反间本阶段一次，先宣告对象和次数，再由目标猜花色、暗选周瑜手牌。暗选沿用 chooseOwnedCard 的一次性 opaque 选项，不向目标泄露手牌实体 ID、名称或顺序。取得后通过普通批量移牌，把交牌与 cards.given 的公开声明同次提交；所有获得/失去牌后效完整结束，才按选中牌的原花色决定伤害。交牌不是弃牌，不调用弃置权限。

已宣告效果不因原技能失去回滚；移牌后来源死亡也不撤销已确定的猜错伤害，目标死亡或终局则停止。支付后手牌已被其他后效取走时自然结束，不造牌、不额外征询，次数仍已消耗。

cards.given 的 visible=true 明确公开牌面，日志与桌面展示牌解释该事实；未标为公开的交牌仍只显示数量和接收者。多张展示共享真实事实序号，以事实序号加牌 ID 区分界面节点，不编造小数序号。这仍不是完整的按观察者维护手牌知识服务，基础 AI 没有对公开后再次隐藏的牌建立推理记忆。

## 阶段技能和客户端

英姿只修改带有显式 draw 阶段句柄的本次摸牌，阶段内普通技能摸牌不继承英姿。闭月在结束阶段开始时询问；跳过该阶段不会触发。接受后失去技能的摸牌继续，死亡/终局仍按当前状态处理。

选将页新增 AI 武将：保留默认预设，也可统一指定所有 AI 席位的武将，便于体验和验证新技能。它不改变主控角色，仍由人类固定控制甲席。手动演练继续使用原机制角色。猜花色和有序目标在桌面/横屏触屏均通过实际控件验证。
