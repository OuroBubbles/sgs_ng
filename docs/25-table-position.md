# 牌桌位置调整

更新：2026-10-27。主要位置关系沿用用户的[参考图](references/table-position.png)，面板和卡牌按用户要求复刻本地 FreeKill 的实际组件组织。

## 区域关系

- 本人席位固定右下，采用完整竖向面板。
- 手牌沿左下排列，数量较多时在自己的区域内横向滚动；技能在本人左侧。
- 确认与取消区居中位于手牌上方，确认在左、取消在右；只有本人有待答请求时显示动作。等待 AI、他人或结算时居中显示状态，本人托管可由左下“收回”交还操作；来源、目标和选择仍由正式规则反馈。
- 对手围绕上方与两侧，中央保留公开用牌与选择空间。窄横屏多人局将对手压成顶部一排，保持操作区域。
- 桌面多人局若两侧分排会使姓名小于约 12px，且顶边足够宽，则将更多席位移至顶边、两侧各保留一席；压缩手牌预留高度，并让中央结算区从顶排下方开始。不能仅以“不越界”代替可读性。
- 装备嵌入角色面板下部，武器与防具分行、两匹坐骑并排，扩展槽另占整行；判定 mark 和席号位于面板底边。
- 牌堆计数位于右上，记录与暂停工具位于左下；手动演练时暂停位置显示藏牌。记录从左侧打开，查看期间隔离游戏快捷键，可关闭或按 Esc 返回。

内容与美术资源的当前范围以 [STATUS](STATUS.md) 为准。

FreeKill 的完整卡面、牌背、花色点数、技能按钮、势力边框、体力图、身份牌、装备栏、判定标记、字体与选中序列以原始字节保存在 [本地资源目录](../src/assets/freekill/provenance.json)，不依赖参考项目的运行目录。按需执行 `node scripts/import-freekill-media.mjs ../freekill` 重新导入；来源、大小与 SHA-256 同步记录，标准立绘也同步替换并更新独立清单。

Enter 在牌、技能与目标选区快捷确认当前草稿；聚焦确认、取消、记录、暂停或说明等命令按钮时执行该按钮自身的原生操作。选区以 `data-selection-input` 显式标记，避免全局确认抢走命令激活。输入框、组合输入和修饰键继续保留原行为。

角色区域选牌复用 [OwnedCardPicker](../src/client/panels/OwnedCardPicker.svelte)，按手牌、装备与判定区分组。未知手牌只传不透明选项与空牌面，显示牌背和编号；公开牌与本人可见手牌使用当前过滤后的正常牌面、花色点数和详情。数字键与点击选择同一选项，公开牌可右键/长按查看，暗牌长按不翻开或误选；长按只抑制本次指针激活，下一次短点与键盘激活可立即进行。查看详情后保留原草稿与请求，仍使用原确认区提交。

## 坐标只有一个来源

[layoutTable](../src/client/table/layout.ts) 接收整张牌桌尺寸，返回席位中心矩形与 arena/hand/decision/skills/choices/ownedChoices/equipment 区域。角色选牌的 ownedChoices 沿用 PlayerCardBox 的分组完整卡牌，牌面和牌背均保持 93×130 比例；面板最高 360px，窄屏缩小卡牌，数量较多时在面板内部滚动。普通文字选项保留 choices，两个区域均避开确认区。

arena 的 top 可以非零；牌池避让使用牌桌中的实际纵坐标，不能将 arena 内部坐标直接与席位中心比较。最近用牌与标题作为整体居中，牌面按结算区高度限制尺寸；不同窗口的宽度上限统一作用于这条约束。

[Pixi 绘制](../src/client/table/board.ts) 与 [Svelte 命中区](../src/app/App.svelte) 使用同一份结果。本人区、技能、装备和确认区不再分别写一组百分比坐标。默认单机围绕固定甲席排列，暂停也不切换焦点；手动演练围绕当前确认角色排列，来源仍是席位投影。

牌桌 DOM 可保留用于布局，但 GPU 战场只属于当前展示的对局；大厅与准备页没有画布或立绘纹理池。返回大厅时销毁渲染器、独占纹理和尺寸观察器，清除旧布局；再次开局创建新实例。异步初始化的拥有者已退出时忽略其完成或错误回调，不让旧实例覆盖新牌桌。对局期间仍按视图变更重绘，不常驻逐帧计时器。

[PlayerPanel](../src/client/panels/PlayerPanel.svelte) 以 FreeKill Photo 的 175×233 坐标等比缩放；photoLayout 同时给出原图、立绘裁取和装备位置。立绘按 PhotoBase 的 PreserveAspectCrop 居中裁取，并直接填充圆角几何；不使用跨渲染器的 stencil mask。姓名与体力竖排在左侧，身份牌右上、手牌数左下，装备与判定使用真实区域按钮；性别和完整状态保留在可访问名称。勾玉保留原始宽高比，空槽与当前体力分层，失去体力时放大淡出；高体力上限沿用单勾玉与数值形式。身份牌、手牌数与底部席号按原图外扩，布局预留底边空间，不再把这些元素挤进立绘。

[EquipmentArea](../src/client/panels/EquipmentArea.svelte) 独立组织 FreeKill EquipArea / EquipItem 的武器、防具、双坐骑与扩展槽；图标、牌名、点数和花色分别定位，不再在 PlayerPanel 中覆盖一整套紧凑牌样式。共用 HandCard 的点击、右键与长按行为，牌名和可选性仍来自过滤后的视图。装备栏不显示手牌数字快捷键角标，坐骑显示 +1 / -1。

[SkillArea](../src/client/panels/SkillArea.svelte) 将主动/转换键按两列组织，被动名称另行排列。[SkillButton](../src/client/panels/SkillButton.svelte) 对照原组件的 80×36 命中区、0.66 倍装饰底图、金色渐变字和失效锁图；底图的透明留白独立于文字和点击范围，普通、选中、禁用态共用原始资源。当前请求的 offers 是可发动性的唯一来源，使用后的主动键保留禁用态；被动名称可打开说明。选区标记只放在真正的选择按钮区域，说明、判定与其他角色装备的 Enter 保留原生命令。

卡牌按 93×130 原图比例展示，当前过滤后的点数、花色叠加在原图坐标；无点数时花色上移，无花色时沿用公开的颜色图标。缺图或解码失败仍可使用文字牌面。手牌、公开牌、排序和详情共用同一卡面绘制，不再叠加旧内框。不可选的手牌与牌池使用 BasicCard 的 35% 黑色遮层，悬停使用白色辉光；选中的手牌上提 20px，暗选面板使用原选中标记。可选、已选与当前行动者按原始序列尺寸、50ms 帧间隔播放；暂停、后台或关闭动画时停止计时。指示线独立于静态 Pixi 牌桌，用两层渐变表现草稿目标及公开用牌；正式用牌按 200ms 伸展、200ms 停留、300ms 淡出，明亮端点和渐变一起伸展，不再擦出一条固定渐变。

布局样式集中在 [surface.css](../src/client/table/surface.css)。旧的按 data-seat、容器高度或设备宽度覆盖席位位置的规则已删除，避免 CSS 再次改变由布局计算出的点击矩形。[style.css](../src/client/style.css) 保留通用控件和牌面样式；[refinements.css](../src/client/refinements.css) 保留选择反馈和详情表现。

## 验证

[布局场景](../src/client/table/layout.test.ts) 使用新的完整牌桌尺寸，验证 2/4/6/8 席位、所有焦点、区域边界、席位不覆盖和主要位置关系。原先 130/155 像素是局部战场高度，不再作为整张牌桌尺寸使用。

[浏览器场景](../tests/browser/client.spec.ts) 额外检查本人右下、手牌左下、确认在上、技能邻近本人、牌堆右上、左侧记录抽屉和徽标尺寸。保留横屏 915×412、竖屏 390×844、真实选牌/响应/装备/暗选/胜负与 Spine 流程。截图为 `.artifacts/ui/reference-layout-desktop.png` 和 `reference-layout-touch.png`；最终结果与原生运行以 [STATUS](STATUS.md) 为准。

八人场景还检查 960×640 桌面窗口中的面板可读尺寸，继续覆盖原有窄横屏、竖屏和席位命中；不另建重复的端到端测试文件。
