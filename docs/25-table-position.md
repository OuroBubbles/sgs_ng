# 牌桌位置调整

更新：2026-10-17。按用户提供的[位置参考图](references/table-position.png)调整区域关系；保留现有视觉语言，不把参考图中的武将、按钮或模式内容当作已实现功能。

## 区域关系

- 本人席位固定右下，采用完整竖向面板。
- 手牌沿左下排列，数量较多时在自己的区域内横向滚动；技能在本人左侧。
- 确认与取消区居中位于手牌上方，确认在左、取消在右；来源、目标和选择仍由正式规则反馈。
- 对手围绕上方与两侧，中央保留公开用牌与选择空间。窄横屏多人局将对手压成顶部一排，保持操作区域。
- 装备/判定区贴近所属角色，本人装备位于本人左侧上方；溢出时在区域内滚动。
- 牌堆计数位于右上，记录与暂停工具位于左下；手动演练时暂停位置显示藏牌。记录从左侧打开，查看期间隔离游戏快捷键，可关闭或按 Esc 返回。

没有添加参考图中的换牌分数、阵营模式、聊天或装饰性假按钮。完整武将与美术资源继续单独推进。

## 坐标只有一个来源

[layoutTable](../src/client/table/layout.ts) 现在接收整张牌桌的尺寸，而不是原来的上半部战场高度。它同时返回席位中心矩形和 arena/hand/decision/skills/choices/equipment 区域。

[Pixi 绘制](../src/client/table/board.ts) 与 [Svelte 命中区](../src/app/App.svelte) 使用同一份结果。本人区、技能、装备和确认区不再分别写一组百分比坐标。默认单机围绕固定甲席排列，暂停也不切换焦点；手动演练围绕当前确认角色排列，来源仍是席位投影。

布局样式集中在 [surface.css](../src/client/table/surface.css)。旧的按 data-seat、容器高度或设备宽度覆盖席位位置的规则已删除，避免 CSS 再次改变由布局计算出的点击矩形。[style.css](../src/client/style.css) 保留通用控件和牌面样式；[refinements.css](../src/client/refinements.css) 保留选择反馈和详情表现。

## 验证

[布局场景](../src/client/table/layout.test.ts) 使用新的完整牌桌尺寸，验证 2/4/6/8 席位、所有焦点、区域边界、席位不覆盖和主要位置关系。原先 130/155 像素是局部战场高度，不再作为整张牌桌尺寸使用。

[浏览器场景](../tests/browser/client.spec.ts) 额外检查本人右下、手牌左下、确认在上、技能邻近本人、牌堆右上、左侧记录抽屉和徽标尺寸。保留横屏 915×412、竖屏 390×844、真实选牌/响应/装备/暗选/胜负与 Spine 流程。截图为 `.artifacts/ui/reference-layout-desktop.png` 和 `reference-layout-touch.png`；最终结果与原生运行以 [STATUS](STATUS.md) 为准。
