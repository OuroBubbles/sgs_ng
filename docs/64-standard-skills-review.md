## 已登记的技能范围

[人工清单](../scripts/standard-behavior-review.mjs) 现在登记全部 40 个标准技能，共 103 条条件，引用 289 条去重后的实际断言。每条保存项目采用的规则文本、条件说明、测试文件和完整测试名称；先核对实现与断言，再登记证据。检查器没有按名称推算覆盖率，也不会把一次整局当作所有分支证明。

本批新增的 25 个技能为：

| 机制       | 技能                         | 核对重点                                                                     |
| ---------- | ---------------------------- | ---------------------------------------------------------------------------- |
| 准备与判定 | 观星、鬼才、天妒、洛神       | 存活人数上限、有序回顶/置底、私有信息、最终判定牌面、嵌套与余牌善后          |
| 受伤后效   | 奸雄、反馈、遗计、刚烈       | 按次/按点机会、真实来源处理区、暗选与取牌权限、私有池、死亡与宣告后失去技能  |
| 主公协作   | 激将、护驾、救援             | 模式授予、当前势力、行动序、供牌者打出与主公使用归属、唯一支付、失败阶段状态 |
| 阶段与手牌 | 突袭、英姿、闭月、克己、连营 | 阶段体替换、显式阶段摸牌、实际活动域、最后手牌批次、后续新机会               |
| 距离与目标 | 空城、马术、谦逊、奇才       | 查询仅作用于声明范围，距离/目标资格分开，实时条件不借用静态武将信息          |

项目采用的具体语义以清单对应文本为准。例如集智接受实体和零材料虚拟普通锦囊，排除有材料转换；裸衣只增加本人实际使用杀/决斗的直接伤害；护驾对杀需要供牌者打出后主公再完整使用闪，对万箭齐发只需实际打出。这些是明确的本项目规则边界，不宣称不同社区版本全部等价。

## 本批补测

[7 项边界场景](../tests/scenarios/standard-trigger-baseline.test.ts) 分别验证：

- 无双不会把万箭齐发的一次打出闪扩大为两次。
- 谦逊和空城各只禁止本人的指定牌名目标，不误伤其他牌、角色或来源用牌。
- 集智不会响应他人的普通锦囊，也不会响应真实奇袭转换的有材料普通锦囊；实际拆牌正常完成。
- 英姿和闭月各不响应他人的对应阶段或本人的其他阶段。

场景同时检查真实回复、材料位置、体力/手牌、无遗留请求/处理区，以及事实重建。对不应出现的发动请求，阶段/他人锦囊测试会主动接受任何意外发动并断言其次数为零，使错误直接表现为行为差异。

观星五张上限已有真实八人场景直接断言，本批没有重复补测。初版新夹具的三项失败是距离豁免参数层级和奇袭事实预期错误，修正夹具后七项通过；Lint 另要求测试助手只抛 Error，已规范。未修改规则内核、标准内容、基础 AI 或生产客户端，未把这些夹具/检查错误计为玩法缺陷。

## 检查与验收边界

```sh
pnpm test
pnpm audit:standard:behavior

# 本批当时有 32 种牌未登记，预期退出 2；当前结果见 65。
pnpm audit:standard:behavior --complete
```

[检查器](../scripts/audit-standard-behavior.mjs) 保持原约束：规则文本必须一致，具名断言必须唯一且通过，当前规则与引用测试不得晚于完整报告开始时间；普通检查只读自有代码。103 条条件对应已核对的具体断言，既不是任意组合覆盖率，也不是整个技能源码的全分支覆盖率。

当前目录状态为 **40/72 对象已登记、32 种牌待审**。普通模式输出 partial；严格完整模式拒绝剩余对象。即使将来全部对象登记，`fullOfflineVerified` 仍保持 false，不能代替完整对局、资源交付、复杂内容与平台验收。后续优先对 32 种牌逐条审阅条件和实际断言，发现证据缺口再补测，发现真实缺陷再修规则。
