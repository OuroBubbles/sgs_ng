# 29 · 魏将、判定后续与独立回合效果

更新：2026-10-17。本批补入夏侯惇、许褚、甄姬，本批时共九名可选标准武将，后续十一武将见 [30](30-strategists-private-pools.md)。继续优先完成离线规则和内容；默认人类甲席与基础 AI、Android 构建后置的边界不变。

## 三名标准武将

实现为 [wei.ts](../src/content/standard/wei.ts) 中的普通函数，只使用 SDK。文本与流程依据本地 FreeKill 的[刚烈](../freekill/packages/standard/pkg/skills/ganglie.lua)、[裸衣](../freekill/packages/standard/pkg/skills/luoyi.lua)、[洛神](../freekill/packages/standard/pkg/skills/luoshen.lua)、[倾国](../freekill/packages/standard/pkg/skills/qingguo.lua)，没有混入界限突破版本。

| 武将   | 基础体力 / 性别 | 技能                                                                      |
| ------ | --------------- | ------------------------------------------------------------------------- |
| 夏侯惇 | 4 / 男          | 一次伤害后可发动刚烈。非红桃判定后，来源弃置两张手牌，否则受到 1 点伤害。 |
| 许褚   | 4 / 男          | 裸衣令摸牌阶段少摸一张，本回合由自己造成的杀、决斗伤害加 1。              |
| 甄姬   | 3 / 女          | 洛神可连续判定并取得黑牌；倾国将一张黑色手牌当闪打出。                    |

刚烈按伤害事件发动一次，不按伤害点数复制。无来源伤害仍可发动判定；判定后只有仍存活的来源才进入弃牌或受伤分支。两张手牌共用联合选择与 `payDiscard`，保护牌和装备不进入费用候选；数量不足直接走受伤分支，不制造无法完成的选择。取消弃牌同样承受伤害，支付完成则不再追加伤害。

倾国复用闪的响应、材料支付和最终资格验证，保留实体材料的花色点数；红牌、装备区和他人的牌不能作为材料。

## 摸牌阶段是一项明确来源

[DrawRequest / DrawDraft](../src/rules/cards/draw.ts) 新增可选 `phase: PhaseView`。只有阶段规则的那次摸牌显式传入；普通技能摸牌不会因为发生在摸牌阶段或使用相同 reason 字符串就继承该来源。默认阶段体已传入实际阶段句柄。

执行侧验证阶段生存期、所属 World、当前祖先路径和角色。`DrawDraft.phase` 保留实时控制句柄，供作者访问关联回合；结果中的 `DrawInput.phase` 只是不可变 `PhaseSnapshot`，不保存函数或生存期句柄。没有关联回合的独立 `runPhase` 不产生裸衣的回合效果。

裸衣只处理本人的显式摸牌阶段摸牌且当前数量大于零。取消不减少数量，也不写增伤状态；发动宣告和增伤状态在一次支付提交中生效，再完成支付后效与数量调整。阶段内的苦肉或其他额外摸牌不被误减。

## 已宣告效果不依赖原技能继续存在

裸衣将独立增伤实例绑定到明确的 Turn Lifetime。同一回合重复摸牌阶段可以再次少摸，但增伤仍是一层，不叠加成每次发动加 1。回合正常结束或规则中止时由现有生存期机制清除。

该批最初由专用 Provider 从状态派生裸衣后效；后续 [56](56-independent-effects.md) 已迁为 `standard:luoyi-effect` 独立实例，费用与实例同次提交，到期自动移除。原始技能失去或失效不会撤销已宣告效果；仍只匹配当前活动回合 ID，嵌套其他回合暂停外层加成，返回后恢复，不把已失去的技能伪装成仍持有。

派生候选在执行前重查状态值和活动回合；窗口内较早的规则若明确撤销这项状态，已收集的增伤候选也不会继续生效。撤销效果状态与失去原始技能是两种不同的操作。

增伤要求伤害来源和牌使用者都是本人，并且是杀或决斗。对方使用决斗、本人作为目标打回时，仍保留本人的实际伤害来源，但不借用裸衣增伤。此处曾采用 noname 的分支，已在 [42](42-skill-identity-audit.md) 按 FreeKill 标准版的 `by_user` 条件修正；不能仅凭非连环或牌名判断。普通技能伤害也不借用该效果；连环与转移后续分别见 [45](45-chain-damage.md)、[46](46-shield-transfer.md)，当前使用 isDirectDamage 明确排除传播与转移副本。

## 判定可以在普通函数内完成后续

[judge](../src/rules/cards/judge.ts) 增加可选 `onResult(ctx, result)`。顺序为：封口并提交结果、开放公共 `judgmentFinished`、调用本次判定的后续、处理区善后。它在结果不可再改判后运行，但仍能取得留在本次处理区中的牌。函数只存在执行侧，不写入事实或 World。

洛神先完成一次发动宣告，再用普通 `while`、`await judge` 和布尔继续选择表达循环。最终改判为黑色才取得对应牌；公共后效已把牌移给别人时不会强取。嵌套同原因判定只调用自己的后续，不被一个按原因匹配的临时全局监听器误收。

整个循环是同一次已宣告技能，失去原技能不会在中途截断；角色死亡、终局、非黑判定、无可用判定牌或选择停止会结束。取得判定牌不是摸牌，不触发 `cardsDrawn`。公开取得有独立事实和中文记录。

## 显式装配需要牌规则的技能

[SkillBook.register](../src/rules/skills/skills.ts) 只在装配期原子追加不可变定义，第一次 `attach` 后目录固定，解除挂接也不重新开放。重复 ID 或无效定义拒绝整批，不留下半注册内容。

[RoleMatch](../src/app/offline/role-match.ts) 的 `skills` 接受定义数组或 `(book: CardBook) => readonly SkillDefinition[]`。先建立牌目录，再调用一次技能工厂，随后验证武将引用并建立 Room。刚烈直接闭包持有传入的牌规则，避免把当前 Room 或 CardBook 塞入全局变量。标准工厂现登记裸衣独立效果定义；包声明/加载见 [39](39-source-packages.md)、[47](47-local-content-modules.md)，独立效果见 [56](56-independent-effects.md)。
