## 弃置不是移动目的地

[CardBook.canDiscard](../src/rules/cards/book.ts) 是纯权限查询，输入 `{ actor, owner, card, reason }`。actor 是执行弃置者，owner 是当前持有者，不能混作一个字段；例如双股剑由目标自行弃牌，寒冰剑由来源弃置目标的牌。该方法检查参与者 ID、终局与实际持有位置，再组合 `cardQueries.prohibitDiscard`。任何 true 否决，false 不能覆盖其他否决；技能失效与来源离场沿用 SkillBook 查询规则。新行动的存活资格由支付/选择/阶段入口检查；已经宣告的效果是否在来源死亡后继续，由其普通流程决定，不在权限查询中统一截断。

查询给修正函数的 [DiscardQuery](../src/rules/cards/discard.ts) 包括区域、当前牌面与材料。card 可以是实体牌 ID，也可以是逻辑延时牌 ID：延时牌按语义牌面查询，materials 表示实时剩余材料，零材料仍有身份。延时牌的材料不能作为独立牌绕过权限；材料已部分离场、附件善后尚未执行的过渡状态也保持整体身份。权限不代替具体技能的区域、目标、距离或数量条件，这些仍由调用者提供。

```ts
modify(cardQueries.prohibitDiscard, (_ctx, { input, self }) =>
  input.owner === self.owner && input.actor === self.owner && input.face.suit === 'heart'
    ? true
    : undefined,
);
```

示例只禁止本人自弃红桃牌，不会自动禁止别人弃置、使用、打出或获得这些牌。理由 reason 可以区分阶段、技能或具体效果，不通过中文提示猜测用途。

## 两个执行入口

- `payDiscard(ctx, book, spec)` 用于弃牌费用。它复用 pay 的所有权/区域、最终条件、次数与宣告原子提交，在支付前补充同一弃置权限检查。不能靠 `legal: () => true` 绕过禁止，失败不部分支付或消耗次数。
- `discardCards(ctx, book, { actor, owner, cards, reason })` 用于效果弃置。先整批校验，再同次提交实体移动与逻辑延时牌状态/区域移除。结果区分 discarded/unavailable，包含逻辑 subjects 与实际实体 cards。零材料延时牌可以只移除身份；事实能够重建。

普通 moveCards 和 pay 不自动把“移到 discard”解释成弃置。用牌材料善后、判定清理、装备替换、死亡埋葬和规则转移保持自身语义。自定义内容也应按实际语义选择入口，不能在底层移动器加入一个全局弃牌堆拦截器。

`chooseOwnedCard` 的 `discard: true` 使候选和最终选择按相同权限过滤。对手暗牌仍是本次不透明选项，不透传实体 ID、牌名或查询牌面。后续执行再查权限；权限在宣告后改变时不会产生虚假的成功弃牌事实。

## 当前标准流程

结姻、贯石斧的候选与费用都使用统一查询；双股剑、寒冰剑、麒麟弓、过河拆桥使用效果弃置。寒冰剑发动前需有可弃牌，宣告后若后效改变剩余资格，已经宣告的防伤不回滚；麒麟弓在宣告后新增保护时不会实际弃置坐骑。顺手的获得流程不受弃置禁止影响。

弃牌阶段按手牌数与上限算原需数量，再取当前可弃牌数量的较小值。可弃牌不足时弃尽可弃部分；没有合法牌时不创建无法完成的必选请求。`discard.limited` 记录原需与实际数量，客户端解释原因，不显示隐藏牌面。受保护牌仍计入手牌数量；“不计入手牌上限”和“不能弃置”是不同规则。

自弃过滤及不足额处理参考本地 [Room.askToDiscard](../../freekill/packages/freekill-core/ltk/server/room.lua)。拆桥保留[本地标准牌](../../freekill/packages/standard_cards/pkg/skills/dismantlement.lua)的非空目标条件：若结算时没有可弃牌，正常空结算，材料不退回。

## 客户端与验证

技能投影保存名称、说明、有效性，界面不读取规则定义或自行计算资格。本人手牌区可打开技能说明，包括没有主动按钮的咆哮；弹窗隔离数字和确认快捷键。选择不合法时主要提示显示预览原因，短横屏也能看到“本阶段使用次数已达上限”。

- [14 项弃置场景](../tests/scenarios/discard.test.ts)：自弃/他弃、来源失效、费用原子性、不足额阶段、私有选项、零/多/部分材料延时牌、普通清理不受误拦、四件武器与结姻，以及麒麟弓宣告后来源死亡仍可继续。
- [8 项武将场景](../tests/scenarios/martial-generals.test.ts)：龙胆双向转换、距离/次数/归属、咆哮失去与重置、奇袭装备/枭姬组合、目录初始化与六席真实胜负。
- 浏览器新增桌面/触屏各两项：龙胆材料与次数，以及被动说明与快捷键隔离。原牌型界面继续回归，Windows 原生另验证龙胆与说明弹窗。
